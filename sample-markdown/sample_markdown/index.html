    2. Định dạng văn bản (Text Formatting)¶

    • In đậm (Bold): **Chữ in đậm** hoặc __Chữ in đậm__
    • In nghiêng (Italic): *Chữ in nghiêng* hoặc _Chữ in nghiêng_
    • In đậm và nghiêng: ***Vừa đậm vừa nghiêng*** hoặc ___Vừa đậm vừa nghiêng___
    • Gạch ngang (Strikethrough): ~~Chữ bị gạch~~
    • Đánh dấu / Highlight: ==Nội dung tô sáng== (tùy parser)
    • Chỉ số dưới (Subscript): H2O (H~2~O) hoặc H<sub>2</sub>O -> H2O
    • Chỉ số trên (Superscript): X2 (X^2^) hoặc X<sup>2</sup> -> X2
    • Gạch chân (Underline): ^^Nội dung gạch dưới^^
    • Phím tắt (Keyboard) Ctrl+Alt+Del: ++ctrl+alt+del++

    ___¶

    Ghi chú (Note)

    Cung cấp thông tin bổ sung liên quan đến ngữ cảnh hiện tại.

    Tóm tắt (Abstract / Summary / Tldr)

    Tóm lược ngắn gọn nội dung cốt lõi của bài viết hoặc giải pháp kỹ thuật.

    Thông tin (Info / Todo)

    Nêu rõ các chi tiết kỹ thuật hoặc lưu ý cần kiểm tra.

    Mẹo thực hiện (Tip / Hint)

    Nhấn F5 trong TwinCAT XAE để nạp chương trình và kích hoạt chế độ Run Mode nhanh.

    Thành công (Success / Check / Done)

    Hệ thống ADS Router đã kết nối thành công tới IPC Beckhoff.

    Câu hỏi & Giải đáp (Question / Help / Faq)

    Làm sao để biết VNC Server đã kích hoạt? Hãy kiểm tra cổng mặc định 5900.

    Cảnh báo (Warning / Caution / Attention)

    Cần cấu hình đúng dải IP tĩnh trước khi ghi đè cài đặt mạng trên Windows CE / TcBSD.

    Lỗi thất bại (Failure / Fail / Missing)

    Không tìm thấy địa chỉ AmsNetId của thiết bị điều khiển đích trên mạng EtherCAT.

    Nguy hiểm (Danger / Error)

    Không rút thẻ nhớ CFast hoặc ngắt nguồn khi PLC đang trong quá trình ghi dữ liệu lưu trữ (Persistent Data).

    Lỗi phần mềm (Bug)

    Phiên bản build 4024.10 có thể gặp xung đột khi kết nối với một số dòng card Intel I210.

    Ví dụ thực tế (Example)

    Cấu hình mẫu cho giao thức ADS qua cổng TCP port 48898.

    Trích dẫn (Quote / Cite)

    "Simplicity is prerequisite for reliability." – Edsger W. Dijkstra

    Bí kíp tối ưu vòng quét Task PLC

    Nên tách riêng Task điều khiển Motion (chu kỳ 1ms) và Task xử lý giao diện HMI (chu kỳ 50-100ms).

    Khung này không có dòng chữ tiêu đề, chỉ hiển thị biểu tượng và nội dung thông báo.

    Bấm vào để xem mã lỗi chi tiết (0x80070002)

    Mã lỗi này biểu thị hệ thống không tìm thấy file cài đặt trong đường dẫn chỉ định. Hãy kiểm tra lại thư mục C:\TwinCAT\3.1\Target.

    Hướng dẫn lấy địa chỉ AmsNetId qua cmd

    Mở Command Prompt và chạy lệnh sau để kiểm tra mạng cục bộ: 

    ping 192.168.1.100

    1. Cắm USB chứa bộ cài đặt vào máy tính IPC.

    2. Khởi động lại thiết bị và bấm F11 liên tục để vào BIOS Boot Menu.

      Cảnh báo thao tác BIOS
